# {{name}}: notes for coding agents

This Vue 2 app was generated by Create InstantSearch App with Vue InstantSearch {{libraryVersion}}.

- The search client and the widgets live in `src/App.vue`. The app searches the `{{indexName}}` index of the Algolia application `{{appId}}`.
- For the index's facets and a suggested widget plan, run `npx create-instantsearch-app introspect --json --app-id {{appId}} --api-key {{apiKey}} --index {{indexName}}`.
- This template still uses algoliasearch v4 (`import algoliasearch from 'algoliasearch/lite'`). With algoliasearch v5 the import is `import { liteClient as algoliasearch } from 'algoliasearch/lite'`.
- Check component props against the installed `vue-instantsearch` version before using them.
- Docs: https://www.algolia.com/doc/guides/building-search-ui/what-is-instantsearch/vue.md (append `.md` to any Algolia docs URL to get Markdown).
- Only the search-only API key belongs in this app. Write and admin keys stay server-side.
{{#unless flags.insights}}
- Insights events are off. Set the `insights` prop on `<ais-instant-search>` to send click and conversion events.
{{/unless}}
- After changing the UI, run `npm start`, type a query, and apply a refinement before reporting success.
