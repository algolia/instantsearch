# {{name}}: notes for coding agents

This Expo app was generated by Create InstantSearch App with React InstantSearch {{libraryVersion}} hooks (`react-instantsearch-core`) and algoliasearch v5. React Native has no DOM widgets: build the UI from hooks such as `useSearchBox` and `useInfiniteHits`, as `src/` does.

- The search client lives in `App.tsx`. The app searches the `{{indexName}}` index of the Algolia application `{{appId}}`.
- For the index's facets and a suggested widget plan, run `npx create-instantsearch-app introspect --json --app-id {{appId}} --api-key {{apiKey}} --index {{indexName}}`.
- Check hook signatures against the installed types in `node_modules/react-instantsearch-core` before using them.
- Docs: https://www.algolia.com/doc/guides/building-search-ui/going-further/native/react.md (append `.md` to any Algolia docs URL to get Markdown).
- Only the search-only API key belongs in this app. Write and admin keys stay server-side.
- After changing the UI, run `npm start`, open the app, type a query, and check that results update.
