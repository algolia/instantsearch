# {{name}}: notes for coding agents

This app was generated by Create InstantSearch App with InstantSearch.js {{libraryVersion}}. InstantSearch.js and the algoliasearch v5 lite client load from a CDN in `index.html`. Your training data likely includes InstantSearch.js v2/v3 code (`addWidget`, string templates); it does not apply here.

- The search client and the widgets live in `src/app.js`. The app searches the `{{indexName}}` index of the Algolia application `{{appId}}`.
- For the index's facets and a suggested widget plan, run `npx create-instantsearch-app introspect --json --app-id {{appId}} --api-key {{apiKey}} --index {{indexName}}`.
- Check widget options against the installed InstantSearch.js version's docs before using them.
- Docs: https://www.algolia.com/doc/guides/building-search-ui/what-is-instantsearch/js.md (append `.md` to any Algolia docs URL to get Markdown).
- Only the search-only API key belongs in this app. Write and admin keys stay server-side.
{{#unless flags.insights}}
- Insights events are off. Set `insights: true` in the `instantsearch()` options to send click and conversion events.
{{/unless}}
- After changing the UI, run `npm start`, type a query, and apply a refinement before reporting success.
